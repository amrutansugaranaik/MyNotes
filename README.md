sample_continue_config.json
- Contains a json file generated by gemini. It has almost all parameters used by continue extension in vscode.
- It has data for a single model in each section and has default values.
- It needs to be places in ~/.continue/config.json file. If config.yml is present, delete it as continue extension first takes yaml and then json.
